# CineMax — نسخة جاهزة للبناء من الجوال

هذه نسخة Flutter أولية لتطبيق CineMax بواجهة عربية RTL وواجهة داكنة.

## الموجود حاليًا

- الصفحة الرئيسية
- بانر مميز
- أحدث الإضافات
- متابعة المشاهدة
- التصنيفات
- الأكثر مشاهدة
- البحث
- قائمة المفضلة
- التنزيلات (واجهة أولية)
- المزيد والإعدادات (واجهة أولية)
- صفحة تفاصيل الفيلم
- شاشة مشغل تجريبية

## البناء بدون كمبيوتر

المشروع يحتوي على `codemagic.yaml` يقوم تلقائيًا بإنشاء ملفات Android ثم يبني APK وAAB على السحابة.

الطريقة المقترحة:
1. أنشئ مستودع GitHub جديدًا من الهاتف.
2. ارفع ملفات المشروع إلى المستودع.
3. افتح Codemagic واربط مستودع GitHub.
4. اختر workflow باسم `CineMax Android`.
5. ابدأ Build.
6. بعد نجاح البناء، نزّل ملف APK من Artifacts لتجربته على هاتفك.
7. عند الجاهزية للنشر، استخدم ملف AAB بعد إعداد توقيع Android.

## مهم قبل النشر

- الصور الحالية تجريبية.
- لا تضع أفلامًا أو مسلسلات محمية بحقوق النشر إلا إذا كنت تملك ترخيص عرضها.
- مشغل الفيديو الحالي Placeholder وليس مشغلًا حقيقيًا.
- يجب إضافة Backend وقاعدة بيانات وتخزين فيديو/بث قبل تحويله إلى منصة فعلية.
- اسم الحزمة الحالي يبدأ بـ `com.cinemax`; يجب اختيار Application ID فريد قبل أول نشر نهائي.
